# Welcome to the Lab Equipment Wiki

This wiki provides quick reference guides for all lab equipment. Each page has a corresponding QR code that you can print and attach to the physical equipment.

## How to Use This Wiki

1. **Find your equipment** in the navigation menu
2. **Read the guide** for basic usage instructions
3. **Download the QR code** from the [QR Codes](qr-codes.md) page
4. **Print and attach** the QR code sticker to the equipment

!!! info "New Members"
    If you're new to the lab, start with the [General Lab Safety](safety/general.md) guide.
